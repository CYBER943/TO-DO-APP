## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, or Edge)
- No additional software or runtime required

### Installation

**Option 1: Clone & Run Locally**

```bash
# Clone the repository
git clone https://github.com/Cyber943/to-do-app.git
cd to-do-app

# Open in your browser
# Simply open index.html directly, or use a local server
```

**Option 2: Using VS Code Live Server**

1. Install [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for VS Code
2. Open the project folder in VS Code
3. Right-click `index.html` and select "Open with Live Server"

**Option 3: Using Python (Local Server)**

```bash
cd to-do-app

# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Open http://localhost:8000 in your browser
```

**Option 4: Using Node.js**

```bash
npx http-server
```

## 💻 How It Works

The To-Do App follows a simple, intuitive workflow:

```
Open App → View Tasks → Create/Edit Task → Manage Task → Complete/Delete Task
```

### Step-by-Step Flow

1. **Open the App** — Visit the live demo or run locally
2. **View Your Tasks** — See all tasks currently saved
3. **Create a Task** — Click the input field and type a new task description
4. **Submit** — Press Enter or click the add button
5. **Manage Tasks** — 
   - Mark as complete by clicking the checkbox
   - Edit descriptions when needed
   - Delete tasks you no longer need
6. **Track Progress** — Watch your completed tasks accumulate
7. **Automatic Save** — Tasks are saved automatically to local storage

### User Interactions

| Action | Result |
|--------|--------|
| **Type in input field** | Prepare new task |
| **Press Enter or click Add** | Create task and add to list |
| **Click task checkbox** | Mark task as complete/incomplete |
| **Click edit icon** | Modify task description |
| **Click delete icon** | Remove task from list |
| **Refresh page** | Tasks remain saved (persistent storage) |

## 💾 Data Storage & Privacy

### How Tasks Are Stored

Tasks are saved locally in your browser using **LocalStorage**, which means:

- ✅ **Your data stays on your device** — No external servers
- ✅ **Complete privacy** — No tracking or data collection
- ✅ **Always available** — Access tasks offline (after first load)
- ✅ **Persistent** — Tasks remain saved between sessions
- ✅ **Fast performance** — No network delays

### Important Notes

- Tasks are stored **per browser** (not synced across devices)
- Clearing browser cache/storage will delete tasks
- No user accounts or passwords needed
- No cloud synchronization (by design, for simplicity)
